📋 Getting Started

1. How to Login

Enter your username and password on the login page. Default credentials:

  • Admin: admin / admin123
  • Receptionist: receptionist / rec123
  • Dentist: dentist / dent123

👤 Patient Management

2. Register a Patient

  1. Go to Patients page
  2. Click "Register Patient" button
  3. Fill in patient details (Name and Contact are required)
  4. Click "Save Patient"

3. Search Patients

Use the search box on the Patients page to search by name.

📅 Appointment Management

4. Create an Appointment

  1. Go to Appointments page
  2. Click "Create Appointment"
  3. Enter Patient Number (e.g., P0001)
  4. Select Dentist, Treatment, Date and Time
  5. Click "Save Appointment"

5. Search an Appointment

  1. Go to Search Appointment page
  2. Enter Appointment Number (e.g., A0001)
  3. Click Search

6. Update Appointment Status

Click the status dropdown on the appointment row and select new status.

💰 Billing

7. Generate a Bill

  1. Go to Billing page
  2. Enter Appointment Number
  3. Add discount if applicable
  4. Click "Generate Bill"

8. Print a Bill

After generating a bill, click "Print Bill" button.

📈 Reports

9. View Reports

  1. Go to Reports page
  2. Select the report type from tabs
  3. Select date range or filters
  4. Click "Load"

🚪 Logout

10. Logout

Click "Logout" in the sidebar to safely logout.
